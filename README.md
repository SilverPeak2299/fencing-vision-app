# Fencing Vision

Fencing Vision is an experimental web application for exploring fencing movement from short video clips. The repository is intended to grow into a monorepo, but its application and deployment boundaries have not been chosen yet.

## Documentation

- [Product brief](docs/product/product-brief.md) — vision, scope, capabilities, and non-goals.
- [User journeys](docs/product/user-journeys.md) — the main user flows the product should support.
- [Requirements](docs/requirements/README.md) — formal, traceable StrictDoc specifications.
- [Interface sketches](docs/design/interface-sketches.md) — provisional routes and data shapes, not committed contracts.
- [Operational notes](docs/design/operational-notes.md) — deferred engineering concerns for later architecture work.
- [Roadmap](docs/product/roadmap.md) — suggested implementation sequence.
- [Open decisions](docs/product/open-decisions.md) — decisions that have intentionally not been made.

The formal requirements describe the product as a system. They do not assume whether it will be implemented as one application or as separate frontend, API, and worker services.
