# Fencing Vision

Fencing Vision is an experimental web application for exploring fencing movement from short video clips. The repository is intended to grow into a monorepo, but its application and deployment boundaries have not been chosen yet.

This Fencing Vision is an application for providing insignt and strucutred
feedback into fencing technique. It uses computervision techniques with user
submited video to extract mettrixs and frame them in a consumable way for
atheletes and coaching staff.

This project uses StrictDoc and a requirments and spec framework for
development, perposes with unit tests that cover spec/requirement coverage.
